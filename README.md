## Projects

### Jaypee Learning Hub
A student-first platform built for my college community. It organizes academic resources — notes, lab materials, previous year question papers, important notices — in a way that's actually easy to navigate. I built this because I was tired of hunting through WhatsApp groups and random drives every time exams came around.

**Stack:** PHP, MySQL, HTML/CSS  
**Live:** [jaypeelearninghub.great-site.net](https://jaypeelearninghub.great-site.net/index.php)

---

### Mirai
An AI-powered collaborative communication platform. Mirai combines intelligent conversation with real-time messaging between users — think of it as a workspace where AI and human communication live in the same place. Still evolving.

**Stack:** Next.js, React, TypeScript, AI integrations  
**Live:** [mirai-pi.vercel.app](https://mirai-pi.vercel.app/)
